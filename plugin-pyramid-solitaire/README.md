# 金字塔纸牌

单人社区插件。使用一副不含大小王的 52 张牌，将 28 张牌摆成七层金字塔，其余 24 张作为只可翻一轮的牌库。目标是消除金字塔内的全部牌。

## 玩法

- A 到 K 的点数依次为 1–13。
- 选择两张可用牌，点数合计为 13 时消除；K 可以单独消除。
- 金字塔牌必须不再被下一层的任何牌压住才可使用。
- 弃牌堆只有最上面一张可与金字塔牌配对；移除后会露出它下面的一张。
- 牌库耗尽且不存在合法组合时，本轮自动结束；清空 28 张金字塔牌即通关。

后端是唯一可信规则源，负责洗牌、判断牌是否露出、验证配对、检测胜负和使用单调时钟计时。每次发牌后，服务端会使用带记忆化缓存的动态求解器验证完整牌序；只有找到至少一条合法通关路径的牌局才会交给玩家。求解只发生在服务端，前端不会收到解法、牌库顺序或弃牌堆中被盖住的牌，玩家仍需逐张翻牌。这里的“可解”表示完整信息下存在通关路径；玩家仍可能因选择不同的配对或翻牌时机而进入死局。

## 插件动作

- `draw`：从牌库翻一张牌。
- `remove`：payload 为 `{ "cardIds": ["牌 ID"] }`（仅 K）或 `{ "cardIds": ["牌 ID 1", "牌 ID 2"] }`（点数合计 13）。
- `reset`：重新洗牌，并清零当前轮次的计时和操作数据。

## 计时、战绩与排行榜

实现方式与汉诺塔一致：服务端以 `time.monotonic()` 计时，前端只在两次服务端快照之间平滑显示时间。通关后 `player_score()` 返回完成毫秒数，详细用时、翻牌次数和消除次数写入公共战绩；登录玩家的通关会由大厅公共排行榜按有效胜场累计，游客局不入榜。

全部源码、界面和测试均位于 `plugin-pyramid-solitaire/`，不需要修改大厅前后端注册表；构建时由插件清单自动发现。
